NSE LIB is a static Astro + TailwindCSS library for browsing Nmap NSE scripts through a cleaner, searchable interface.

It includes:

- Official NSE scripts imported from Nmap
- Unofficial community scripts imported from curated GitHub sources
- Static detail pages with usage, references, output preview, and script source

## Stack

- Astro
- TailwindCSS
- Astro Content Collections
- Fuse.js for client-side fuzzy search

## Development

Install dependencies:

```sh
npm install
```

Start the local dev server:

```sh
npm run dev
```

Create a production build:

```sh
npm run build
```

Preview the built site locally:

```sh
npm run preview
```

## Content Structure

Official and unofficial entries are stored as Markdown content:

- `src/content/scripts/official`
- `src/content/scripts/unofficial`

Raw `.nse` source files are stored separately and rendered on each script page:

- `src/data/script-source/official`
- `src/data/script-source/unofficial`

The content schema is defined in [src/content.config.ts](./src/content.config.ts).

## Sync Commands

Refresh the official NSE catalog from Nmap:

```sh
npm run sync:official
```

Refresh the unofficial NSE catalog from the Deadjakk mirror:

```sh
npm run sync:unofficial
```

These commands regenerate the Markdown entries and the stored `.nse` source files.

## Contributing

Contributions are welcome. You can help improve the project in a few different ways:

- add missing metadata
- improve descriptions, usage examples, and references
- fix import edge cases
- improve search, filtering, and page layout
- add support for additional unofficial script sources

### Adding or Updating Script Content

For small fixes, edit the generated Markdown entry directly inside:

- `src/content/scripts/official`
- `src/content/scripts/unofficial`

If you need to update stored source code for a specific entry, edit the matching file in:

- `src/data/script-source/official`
- `src/data/script-source/unofficial`

For large catalog refreshes, prefer rerunning the importer scripts instead of editing many generated files by hand.

### Adding New Official Scripts

Official content is generated by:

- [scripts/import-official-nse.mjs](./scripts/import-official-nse.mjs)

To refresh the full official catalog:

```sh
npm run sync:official
```

If Nmap adds or changes scripts upstream, this is the command to run.

### Adding New Unofficial Sources

If you want to support another unofficial source, the recommended workflow is:

1. Add a dedicated importer under `scripts/`.
2. Normalize the imported metadata into the existing content schema.
3. Store Markdown entries under `src/content/scripts/unofficial`.
4. Store raw `.nse` files under `src/data/script-source/unofficial`.
5. Add a package script in `package.json`.
6. Run `npm run build` to verify the generated content renders correctly.

### Contribution Checklist

Before opening a PR:

1. Run `npm run build`.
2. Verify the homepage search still works.
3. Open a few generated script pages and confirm references, attribution, and source blocks look correct.
4. Make sure unofficial entries point to the original creator when that information is available.
